## Foundation
- RuntimePaths: explicit CODE_DIVER_HOME overrides every config/cache/data/state/
  host/service path; never mutate HOME. Linux XDG defaults, native macOS defaults.
- RuntimeConfig: versioned TOML, profile endpoints/collection/artifact/manifest/
  index identity, daemon loopback defaults, autostart, timeout, child limits.
- Load/save config atomically; precedence flags > injected env > file > defaults;
  named secret references only, private 0600 file store and fakeable keychain trait.
  Redacted Debug/config dump; errors omit input values, response bodies and URLs.
- Profiles from local TOML or HTTPS with bounded size, timeout and redirects.
- Embedded Pier manifest from git show 53d881e0:tools/pier-local/sidecar/models.json;
  preserve exact hashes/sizes, min llama build 9430, dimensions 1024.
- Stream downloads, optional sensitive HF bearer header, HTTPS or loopback HTTP
  tests; same-origin redirects only, range resume, reject malformed Content-Range,
  restart if range ignored, exact bytes/SHA256, atomic finalize, per-model lock,
  progress callback (consumer writes stderr), preserve partials on interruption.
- Local mocks and temp paths, no real model/network dependency; fmt and strict
  Clippy on standalone foundation target.

## Consumer handoffs (architect assigns)
1. CLI/setup: add setup/daemon/update-index/doctor/config surface and integrate
   runtime config with existing service config; preserve legacy YAML and path
   semantics and global flags. Ask only when necessary; idempotent repair,
   platform/build detection, explicit llama path, confirmed brew on macOS,
   exact Linux install hint, no sudo; token input never echoed.
2. Daemon: supervise two lazy llama children, crash recovery, idle stop 600s,
   bounded concurrent requests/timeouts and capped rotating logs. Embedder
   --embedding --pooling last, ctx5120, batch/ubatch2560; reranker
   --embedding --reranking --pooling rank,
   ctx16384, batch/ubatch >=4096, NO --parallel (measured owner facts override
   older docs). Explicit container CPU threads. Loopback only, Host check,
   JSON-only POST, /v1/embeddings /v1/rerank /v1/models /health; 503 reason/504,
   never empty success; MCP/index use configured daemon URLs and autostart.
3. Service/host integration: launchd user/systemd --user, foreground container
   mode, additive Claude/opencode/Codex/Gemini detection/registration, backups,
   diff preview, --no-register. Under override use only RuntimePaths.hosts and
   service paths, never discover/write actual user host files. Uninstall only
   owned entries/service/config; retain cache/models unless --purge.
4. Shared index: bearer-auth fetch catalog/graph/metadata, SHA256 validation,
   metadata model compatibility, atomic generation swap and changed summary.
   Never mutate production Qdrant collections; scratch names zz_* only.
5. Doctor: platform/build/models/daemon/dimension+norm/short+long rerank/Qdrant
   auth+collection+vector size/artifact freshness/host registration/disk+RAM;
   PASS/FAIL with fix lines, JSON, nonzero FAIL. Real-model isolated-port RSS/
   latency measurements later, never stop existing services.
6. Distribution/docs: static-ish mac arm64/x86_64 and Linux x86_64/aarch64
   releases/checksums, single-file installer to ~/.local/bin invoking setup;
   optional Docker, one-page colleague guide without internals.
