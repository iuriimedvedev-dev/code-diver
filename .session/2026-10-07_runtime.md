- CODE_DIVER_HOME absolute override uses config/cache/data/state/hosts/services
  children without consulting HOME or XDG. Default Linux paths use XDG and
  ~/.local/state; macOS uses Library/Application Support and Library/Caches,
  LaunchAgents. Host/service consumers must honor isolated paths, not OS discovery.

  Private atomic files are0600, secret directory0700; keychain is injected via
  MacSecurity: SecretStore, not a subprocess carrying secrets in argv.
- Downloads use TLS verification and bounded timeouts, sensitive auth headers,
  same-origin redirects only, .part range resume, strict Content-Range/length,
  streaming writes, exact SHA256+size, fsync+atomic rename and per-file lock.
  Interrupted partials survive; complete corrupt partials are discarded. Existing
  final models remain unchanged until a replacement is verified. Stale locks
  require manual checking; no unsafe automatic lock deletion.

- RuntimeConfig public fields schema,profile,daemon,llama_server,secrets;
  Default, validate(), daemon_url(), redacted_toml().

  model_manifest_url,index_name,embedding_model,embedding_dimensions,
  query_prefix,document_prefix; load_profile(source: &str) async -> RuntimeProfile

  save_config(&Path,&RuntimeConfig); missing file gives defaults, malformed file
