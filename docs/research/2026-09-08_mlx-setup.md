## MLX/Metal runtime evidence

The finite inline check used packaged `mlx.core` APIs, set the default device
to `mx.gpu`, evaluated a `1024 x 1024` matrix multiplication, and called
`mx.synchronize()` before measuring completion.

```sh
HF_HUB_CACHE="$PWD/.tmp/mlx-model-cache/huggingface" \
  .tmp/mlx-runtime/bin/python - <<'PY'
import time
import mlx.core as mx

mx.set_default_device(mx.gpu)
print("default_device", mx.default_device())
print("metal_available", mx.metal.is_available())
print("active_memory_before", mx.get_active_memory())
print("cache_memory_before", mx.get_cache_memory())
print("peak_memory_before", mx.get_peak_memory())
a = mx.random.normal((1024, 1024))
b = mx.random.normal((1024, 1024))
mx.eval(a, b)
mx.synchronize()
start = time.perf_counter()
y = a @ b
mx.eval(y)
mx.synchronize()
print("forward_shape", tuple(y.shape))
print("forward_dtype", y.dtype)
print("synchronized_forward_seconds", f"{time.perf_counter() - start:.9f}")
print("forward_finite", bool(mx.all(mx.isfinite(y)).item()))
print("forward_checksum", float(mx.sum(y).item()))
print("active_memory_after", mx.get_active_memory())
print("cache_memory_after", mx.get_cache_memory())
print("peak_memory_after", mx.get_peak_memory())
PY
```

## Qwen3 reranker model evidence

The requested model was loaded through the packaged `mlx_lm.load` API. The
cache was redirected with the supported `HF_HUB_CACHE` environment variable;
no model files were placed in the user's global cache.

```sh
HF_HUB_CACHE="$PWD/.tmp/mlx-model-cache/huggingface" \
  .tmp/mlx-runtime/bin/python - <<'PY'
import time
import mlx.core as mx
from mlx_lm import load

model_id = "mlx-community/Qwen3-Reranker-0.6B-4bit"
model, tokenizer, config = load(model_id, lazy=False, return_config=True)
text = "Query: mlx gpu\nDocument: MLX runs tensor computation on Apple Silicon."
tokens = tokenizer.encode(text)
inputs = mx.array([tokens[:128]], dtype=mx.int32)
mx.eval(inputs)
mx.synchronize()
start = time.perf_counter()
output = model(inputs)
mx.eval(output)
mx.synchronize()
print("model_config_model_type", config.get("model_type"))
print("forward_shape", output.shape)
print("forward_dtype", output.dtype)
print("synchronized_forward_seconds", f"{time.perf_counter() - start:.9f}")
print("forward_finite", bool(mx.all(mx.isfinite(output)).item()))
print("forward_checksum", float(mx.sum(output).item()))
PY
```
