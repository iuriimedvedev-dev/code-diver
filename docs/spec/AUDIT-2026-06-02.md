# Code Diver — Delta Audit (2026-06-02)

**Scope:** code committed since `2ac4147` (the prior audit's HEAD) — 8 commits covering
symbol-first hybrid scoring, the adaptive agentic search loop, streaming/append indexing,
JVM symbol extraction, deterministic-indexing toggles, and the local-model
(embedding + reranker) provider robustness work.
**Method:** read-only review of the changed code + the new 2026-06-01/02 eval reports.
Companion to [`AUDIT.md`](./AUDIT.md); only NEW findings are listed here.

---

## Verdict

> The new work is directionally right (symbol signal, JVM coverage, local-model pivot,
> incremental indexing) but it introduced **one critical data-integrity regression** and a
> family of **silent-degradation traps** that are especially dangerous because they fail
> quietly during *benchmarks* — the one place this project must be trustworthy.

The headline: **streaming indexing can leave a half-written Qdrant collection with no
error and no detection on the next search.** Below it sits a recurring pattern — the
local-model robustness shims (loose JSON rerank parser, `reasoning_content` fallback) and
the agentic evidence gate all **substitute a plausible-but-wrong result for a clean
failure**, which is the same fail-silent anti-pattern flagged in the original audit, now
reappearing in new code.

## Cross-cutting observations

- **The fail-silent theme from the original audit is spreading into new code.** I-1W, AG-1,
  AG-2, P-1, P-3 all replace a clean failure with a plausible wrong answer. For a tool whose
  product *is* trustworthy eval numbers, this is the most important pattern to reverse —
  see the still-open **A-1 / R-8** "add an explicit `degraded` signal" recommendation.
- **Prior open findings untouched:** A-1 (error swallowing), R-1/R-2/R-4..R-8 (scoring
  contract + golden tests), I-10 (embedding retry). **I-1 was made worse** by streaming.
- **Local-model serving mismatch (not a code bug, but a root cause):** the reranker is a
  *generative* model (Gemma/Qwen-instruct) driven through Ollama/MLX, which expose no true
  cross-encoder rerank endpoint. This — not the embedder — is the most likely cause of the
  0.62 (local) vs 0.78 (cloud) Hit@1 gap. See the proposals doc.

## Remediation priority

1. **I-1W (Critical):** make streaming indexing transactional — write to a temp/shadow
   collection and atomically swap on success, or keep the old collection until all blocks
   commit; on any block failure, abort without destroying the prior index. At minimum,
   write an index-complete marker and refuse search on a partial collection.
2. **AG-1 / AG-2 (High):** add a remaining-round guard to the adaptive gate
   (`if round_index >= MAX_ROUNDS-1: return False`), prefer the model's parsed results over
   raw fallback paths, and emit an observable `degraded`/`adaptive_incomplete` flag.
3. **P-3 / P-1 (Med):** prefer constrained/JSON-schema decoding for local rerankers; on
   parse failure, fall back to the *original* order (no rerank) rather than a regex-salvaged
   one, and surface `rerank_degraded=true`. Return `""` (not scratchpad) on empty `content`.
4. **J-1 (Med):** extend `_CONTROL_WORDS` / anchor the method regex so leading
   `return`/`throw`/`new` statements aren't parsed as definitions.
5. **D-1 (Med):** warn (or hard-error) when `line_chunks=false` is combined with
   `structural_chunks=true`.
